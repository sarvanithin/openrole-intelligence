Public read-only API

Build from evidence.

Search verified U.S. openings, inspect H-1B evidence tiers, and monitor source freshness. Responses are JSON, bounded, paginated, and rate limited.

Endpoints

GET /api/jobs

Search definite U.S. roles with q, company, location, tier, status, limit, and offset. Ambiguous and non-U.S. locations are never returned.

GET /api/jobs/{id}

Read a privacy-limited description excerpt and the evidence used for one assessment.

GET /api/companies

Search public company identities with q, limit, and offset; inspect active-job coverage and freshness.

GET /api/coverage

Inspect the complete company denominator and auditable discovery, approval, and successful-source counts. Directory inclusion alone is not coverage.

GET /api/h1b-employers

Search legal employer names from imported official DOL H-1B disclosure data.

GET /api/sources/status

Inspect public source health without internal URLs or error details.

GET /api/methodology

Read machine-readable tier definitions and the legal disclaimer.

Machine-readable contract

The complete OpenAPI 3 document is available at /api/openapi.json. Treat evidence scores as ordering signals, never sponsorship probabilities.

curl 'https://your-host.example/api/jobs?q=data&tier=A&limit=25'
